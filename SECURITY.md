# Security policy

Mju Agents is local-first software, but it can access the selected
workspace and configured model/MCP providers. Treat the local server and all
provider credentials as sensitive.

Do not report secrets, API keys, cookies, client materials, or full private
transcripts in a public issue. Redact paths and credentials from any report.

When reporting a suspected vulnerability, include the smallest safe
reproduction, affected version, operating system, and whether the server was
bound to localhost or a network interface. Use the private security channel
configured for the public repository.
