# 案卷当下状态治理

本文件是 `config/agent-hub/shared/case-context-schema.yaml` 的可执行说明。进入既有案卷、新建或修改案卷级产出时均须读取。

## 固定读取顺序

1. 案件主文件；
2. `AI协作/案件状态快照.md`；
3. `任务/`、`日程/`、`期限/`、`大事记/`；
4. 与当前事项有关且已标明效力的分析；
5. 对应材料与外部原文。

快照是当前有效认知的唯一入口。快照为空或是占位内容时，依据已有案卷文件形成候选，并把无法确认的内容标为“待核实”，不要求用户维护。

## 文件边界与效力

- `材料/`：外部原始事实、证据和来源；
- `分析/`：法律研究、证据分析、路径推演、策略决策和复盘；
- `文书/`：案卷级定稿、提交或交付文件；
- `工作包/`：一次事项的材料、分析、文书和交付记录；
- `AI协作/`：快照与交接控制层。

分析文件补齐：`分析类型`、`判断效力`、`适用阶段`、`复核日期`、`author_role`、`review_state`。旧分析没有 `判断效力` 时默认“历史参考”，核验前不得作为当前结论。

## 结束动作

1. 回写受本次事项影响的分析效力；
2. 更新快照和交接记录；
3. 将新行动归入任务、日程、期限或大事记；
4. 仅提出可迁移判断候选，不自动写入知识库。
